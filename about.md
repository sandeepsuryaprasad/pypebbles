<h1 class="articles-heading">About</h1>

Hi, I'm Sandeep, a seasoned Quality Assurance professional with more than 20 years 
of experience as an Automation developer, with deep expertise in 
Python-driven automation. Over the last decade, I have focused on designing 
and implementing scalable, reliable, and maintainable automation solutions 
for UI and API testing using Python, Selenium and related technologies.

**Pypebbles** is my way of sharing that knowledge, along with the practical examples and 
insights that I have gained through years of working with Python.

I am an active open-source contributor to the Selenium Python client, with more than 
50 accepted and merged pull requests. My contributions include designing and 
implementing Python descriptors to improve the maintainability and extensibility of 
the client library. You can explore my contributions to the Selenium Python client on

  GitHub Repo
